قولاي تور سودىسى — تور بەت كودلىرى

بۇ ZIP نىڭ ئىچىدە تور بەتنىڭ كودلىرى، سۈرەتلىرى، خەت نۇسخىسى، ئۈچ تىل ۋە Vercel تەڭشىكى بار.
بوتنىڭ كودى، ئاچقۇچلىرى، خېرىدار ئۇچۇرلىرى ۋە سانلىق مەلۇمات ئامبىرى قوشۇلمىغان.

Node.js قاچىلانغان كومپيۇتېردا بۇ قىسقۇچ ئىچىدە npm run dev نى ئىجرا قىلىپ،
http://127.0.0.1:5173/ نى ئېچىڭ.

باشقا Vercel ھېساباتىدا يېڭى تۈر ئېچىپ مۇشۇ قىسقۇچنى يوللىغىلى بولىدۇ.
چىقىرىش قىسقۇچى: public. ئالدىنقى ھېساباتقا باغلانغان .vercel ھۆججىتى يوق.

دەسلەپ مۇستەقىل سىناق نۇسخىسى ئېچىلىدۇ؛ ھەقىقىي سېتىۋېلىش، پۇل قاچىلاش ۋە
خېرىدار قالدۇقى ئۈچۈن بوتنىڭ ئارقا مۇلازىمىتىنى قايتا ئۇلاش كېرەك.
ئۇلاش ئۇسۇلى README.md دا تولۇق يېزىلغان.
